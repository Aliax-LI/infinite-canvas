# Pending Tests

The current release needs manual verification in these areas:

- Image Studio dialog image paste support: in `/image` conversation composer, pressing `Cmd+V` / `Ctrl+V` (or right-clicking Paste) while focused on the prompt input or composer box with an image in the system clipboard (from screenshots, image copying in browsers, or file manager) automatically uploads the image to local storage, appends it into the reference image list with visual toast feedback, and displays its thumbnail in the reference strip above the input. Plain text pasting into the textarea remains completely unaffected.

- Generation logs button styling, typography unification & mobile optimization: in `/image` history drawer (`生成记录`), the top bar layout is unified on a single continuous horizontal line on the left (`生成记录` title and `共 N 条` count strictly aligned along the text baseline with `leading-none`, vertical divider, `全选` and `删除` batch actions) with the close button positioned cleanly on the top-right corner. All buttons across the drawer header and cards (`全选/取消`, `删除`, `载入工作台`, `重试`, `复制`) have all box borders, drop shadows, and focus outlines (`border-0 shadow-none outline-none ring-0`) removed. Selected checkboxes across both daytime and nighttime themes feature explicit high-contrast checkmarks (`!text-white stroke-white` on dark in light mode, `dark:!text-stone-900 dark:stroke-stone-900` on white in dark mode), fixing the Ant Design text color inheritance bug that previously caused solid black/white filled circles without checkmarks. Mobile touch devices have no hover capability, so action buttons and selection checkboxes are permanently visible on touch/mobile screens, long prompt text can be tapped to expand the full text, and clicking the image opens the large high-res lightbox preview.
- Generation logs interaction swap and dual-theme compatibility: clicking any part of an image card thumbnail directly opens the full-resolution lightbox preview (`放大预览`), aligning with natural gallery expectations. Loading prompt, reference images, and parameters into the composer is triggered explicitly by the hover action bar's primary "Load to Composer" (`载入工作台`) button, providing immediate toast confirmation (`已载入到生图工作台`) and closing the drawer. Both Light and Dark mode color palettes are rigorously verified: header actions and card action buttons adopt neutral flat styling, eliminating stark solid black pill blocks in light mode and inverted blocks in dark mode.
- Dark mode contrast and image studio styling: in dark mode, the image settings popover controls (aspect ratio, resolution, quality, count, dimensions, transparent switch) no longer render as stark white/light-grey tracks with inverted text, using proper recessed dark tracks (`dark:bg-stone-950/60`), muted unselected options (`dark:text-stone-400`), and elevated selected cards (`dark:bg-stone-700 dark:text-white`). Failed generation cards in conversation flow render with subtle dark rose borders and backgrounds, distinct alert badges, readable error messages, and accessible retry buttons. In the generation history drawer (`生成记录`), action buttons have been restyled with neutral elevated borders, removing solid black pill blocks in light mode and inverted white blocks in dark mode; model labels use clean names without raw channel prefixes (e.g. `gpt-image-2` instead of `default::gpt-image-2`).
- Generation logs gallery layout and interaction: `/image` history panel (`生成记录`) transitions from uneven, vertical-first CSS multi-columns to a balanced, responsive CSS Grid (`grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 xl:grid-cols-6 2xl:grid-cols-7` within a 1680px max-width container). Generation records flow strictly chronologically from newest to oldest row by row with uniform 4:5 aspect ratio cards, eliminating jagged heights and blank right-side voids. Single-row top header harmonizes the close button, title, item count pill badge, new session action, select all, and danger batch-deletion. Failed/no-image records are formatted cleanly with alert badges, readable prompt text, timestamps, and retry actions without awkward dark gradient covers. Image cards feature a zoom preview on thumbnail click, a rounded hover-revealed selection check, prompt preview with time/model tags, and a hover quick-action bar for loading directly into the composer (`载入工作台`), opening high-res lightboxes, copying prompts, and single-item deletion.
- Model picker dropdown redesign & mobile compactness: the dropdown panel reflects modern AI tool styling with a clean localized section header (`选择模型` / `Select model`), rounded-xl item rows featuring brand model icons, medium model labels, dedicated rounded channel pill badges (e.g. `Sub2api`), and right-aligned checkmarks for the active model. The trigger is completely borderless and seamless (`border-0 bg-transparent shadow-none`) with a dynamic flipping chevron indicator and gentle hover feedback (`hover:bg-black/5 dark:hover:bg-white/10`). On mobile screens (`< 640px`), the trigger is constrained to a compact width (`max-w-[125px] sm:max-w-[200px]`) displaying only the primary model name without appending channel suffixes, preventing it from stretching across the screen or cramping adjacent controls.
- Image Studio conversation & message styling: `/image` features a left/right chat stream above the composer. Generated images render as proportionally constrained thumbnail cards (`max-h: 300~360px`, `max-w: 280~360px`) hugging the image tightly without oversize screen domination or artificial letterboxing/black bars, while clicking anywhere on the card triggers the full-resolution preview lightbox. All heavy box borders have been removed across prompt bubbles, image results, error cards, and metadata tags, adopting a pure, borderless, modern aesthetic. Prompt bubbles render in soft neutral rounded bubbles with embedded reference thumbnails, fill-composer action, and instant copy feedback. Result cards feature a clean borderless image with full aspect-ratio fidelity and discreet monospace dimensions with floating flat action buttons underneath. Failed cards use square 240px slot cards (`aspect-square`) with centered alert icons, error details, and retry actions, matching pending loaders and image slots.
- Navigation: desktop top nav and the mobile drawer should no longer show Video Studio; Image, Prompts, Assets, and Config remain. Opening `/video` directly or via Agent should still reach the page. The header should no longer show the version number or the GitHub icon. When the main top nav already has Config, the top-right should not show a second config button; inside a canvas the gear should still open config.
- Prompt Center: NSFW / restricted prompts stay hidden with no toggle. Filters are a Chinese source dropdown and a searchable Chinese topic-tag select; English tags, author handles, and NSFW tags should not appear.
- Canvas image previews: canvas image nodes, the left element list, the node reference bar, my-assets cards, the asset picker, image workbench result cards and history thumbnails, and the image/video workbench reference strips all render from a preview capped at a 768px long edge, so image-heavy views no longer decode the originals. Opening the full-size image, editing, downloading, exporting, and generation references must keep using the original; an image that is already at or under 768px, exists only as a remote URL, or uses a custom cover should fall back to the original.
- Canvas drag and connection rendering performance: Dragging a single node, a multi-selection, or a whole group should stay responsive, and the drop position after releasing should match the dragged preview. When zoomed or panned so only part of the canvas is visible, every connection crossing the viewport should still render (including ones whose endpoints are both off-screen), connection click selection and the context menu should still work, and the dashed preview while creating a connection should follow the cursor as before.
- Local proxy: Settings should show a dedicated Local proxy tab between Providers and Preferences, with a switch that is off by default. Turning it on should reveal the `npx @basketikun/canvas-proxy@latest` command (with `--port` appended when a non-default port is configured), a copy action, and an address field defaulting to `http://127.0.0.1:23210` that normalizes a missing scheme and trailing slashes on blur. Video settings keep `480p` / `720p` / `1080p` (plus custom `p`) and `1:1` / `3:4` / `4:3` / `16:9` / `9:16` / `21:9` / auto, filling W/H from that pair. ## 图片分辨率尺寸表

选择分辨率和宽高比后，W/H 按下表填写，单位为像素。预设尺寸不受「16 倍数对齐」开关影响；该开关只控制手动输入尺寸时的对齐。最终生成尺寸以所选模型的实际输出为准。

| 宽高比 | 1K | 2K | 4K |
| --- | ---: | ---: | ---: |
| **1:1** | **1024 × 1024** | **2048 × 2048** | **2880 × 2880** |
| **2:3** | 1024 × 1536 | 1360 × 2048 | 2336 × 3520 |
| **3:2** | 1536 × 1024 | 2048 × 1360 | 3520 × 2336 |
| **4:3** | 1024 × 768 | 2048 × 1536 | 3312 × 2480 |
| **3:4** | 768 × 1024 | 1536 × 2048 | 2480 × 3312 |
| **16:9** | 1536 × 864 | 2048 × 1152 | **3840 × 2160** |
| **9:16** | 864 × 1536 | 1152 × 2048 | **2160 × 3840** |
| **21:9** | 2016 × 864 | 2688 × 1152 | **3840 × 1648** |
| **9:21** | 864 × 2016 | 1152 × 2688 | **1648 × 3840** |

待验收：

- 在画布和图像工作台逐项切换 3 档分辨率与 9 种比例，W/H 应与表格一致，重新打开设置后仍选中正确档位；重点检查 1K 的 2:3、16:9、21:9 及对应竖图，以及 4K 的 1:1。
- 所有 4K 预设提交时均不应触发本地总像素或最长边限制；生成和编辑请求、调用脚本应收到所选像素尺寸。
- 分辨率为自动时保留比例选择，比例为自动时禁用 W/H；手动输入 W/H 后，对齐开关仍应按原有方式工作。
- Gemini 在质量为自动时，应将表中尺寸识别为对应的 1K / 2K / 4K；显式选择质量时维持原有优先级。视频尺寸设置应保持原有行为。
